# LedgerLens

LedgerLens is a multi-tenant financial document intelligence platform.
Users authenticate, upload statement files via presigned object-storage URLs, and receive deterministic analytics generated by an async ingestion pipeline.

## What the project does

- Authenticates users (JWT access + refresh-session lifecycle)
- Uploads files directly to S3-compatible storage (MinIO/S3)
- Processes ingestion asynchronously via Redis + BullMQ worker
- Normalizes transactions into Postgres
- Serves materialized analytics (monthly/category summaries) and dashboard APIs
- Enforces per-user data isolation on document and analytics routes
- Adds reliability/security patterns (idempotency, throttling, observability hooks)

## Tech stack overview

- **Backend:** NestJS, TypeScript, Node.js
- **Auth/Security:** JWT, Passport, bcrypt, refresh-token rotation/revocation, class-validator
- **Database/ORM:** PostgreSQL, Prisma, SQL migrations
- **Queue & async:** Redis, BullMQ
- **Storage:** S3-compatible object storage (AWS SDK v3)
- **Frontend:** React 18, TypeScript, Vite, React Router, Recharts
- **Observability:** Pino (`nestjs-pino`), health/readiness/metrics endpoints, worker queue/job metrics logging
- **Testing/tooling:** Jest, Supertest (e2e), pnpm workspaces
